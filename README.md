`main.ts` writes a two-line explanation of an everyday thing to
`/output/entry.txt`: line 1 explains a queue to a 10-year-old through a
caterpillar analogy, and line 2 says what the analogy maps and what it
leaves out.

Run it with Node 22+: `node main.ts`.
